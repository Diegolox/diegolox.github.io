## Proyectos destacados

### [TheBUG01](https://github.com/Diegolox/TheBUG01)

**Robot diferencial plug-and-play para prototipado rápido y educación**

<p align="justify">
TheBUG01 es una plataforma robótica basada en una <strong>PCB todo-en-uno</strong> para un robot diferencial de dos ruedas, pensada para reducir cableado, acelerar el prototipado y facilitar la integración de hardware y software.
</p>

**Aspectos técnicos principales**

* PCB de control con periféricos integrados
* Basado en **ESP32**
* **IMU** para estimación de orientación y movimiento
* **3 sensores TOF400 por I²C** para detección de obstáculos
* Driver dual **TB6612FNG** para control de motores DC
* Convertidor **DC-DC** integrado
* Protección frente a **back-EMF**
* Diseño orientado a educación y robótica experimental

<details>
  <summary><strong>Qué incluye el proyecto</strong></summary>
  <ul>
    <li>Diseño del circuito impreso</li>
    <li>Desarrollo de firmware para control y sensórica</li>
    <li>Integración de motores y sensores</li>
    <li>Diseño 3D del prototipo</li>
    <li>Base para control de velocidad, cinemática diferencial y navegación básica</li>
  </ul>
</details>

**Tecnologías:** `C` `C++` `KiCad` `Fusion 360`
